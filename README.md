# Aplikasi Tes Psikologi PAPI Kostick

Aplikasi web responsif untuk pelaksanaan tes kepribadian **PAPI Kostick** (90 pasang pernyataan *forced-choice*, 20 dimensi) dengan akun Peserta dan Admin, grafik radar, penyimpanan lokal sinkron, integrasi Google Sheets, serta ekspor Excel (`.xlsx`) 3 sheet.

## Cara Menjalankan / Deploy
1. Ekstrak seluruh isi arsip ini dan unggah ke repositori GitHub Anda.
2. Aktifkan **GitHub Pages** (Settings > Pages > Branch `main` / `/ (root)`) atau hubungkan ke Vercel/Netlify.
3. Untuk sinkronisasi otomatis ke Google Spreadsheet, masuk sebagai Admin di aplikasi dan ikuti panduan pada menu **Integrasi Google Sheets**.
